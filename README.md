# Interactive Sustainable Campus 3D

A polished browser-based 3D campus experience exploring how sustainability-focused infrastructure can be integrated into a modern academic environment. The project is a conceptual visualization rather than a survey-accurate digital twin.

## Features
- Interactive 3D campus built with Three.js and WebGL
- Renewable energy and rooftop solar systems
- Rainwater harvesting and water reuse
- Green-building concepts and landscaped public spaces
- Waste segregation and composting hub
- Biodiversity garden and pond
- Cycling network, EV charging and electric campus mobility
- Academic buildings, residences and sports grounds
- Clickable sustainability markers and information panels
- Smooth camera transitions and guided campus tour
- Responsive glass-style interface

## Technology
- Three.js
- JavaScript
- HTML5
- CSS3
- WebGL

## Run locally
Open the folder in VS Code and launch `index.html` with Live Server. Alternatively, run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`. Internet access is required for the Three.js CDN and Google Fonts.

## Project note
This project is an original conceptual sustainable-campus visualization created for interactive web exploration. Building names and sustainability systems are used as elements of the fictional campus experience.
